# Sponsoring-Pakete verwalten

Sponsoring-Pakete sind Vorlagen wie Bronze, Silber, Gold oder Hauptsponsor, die du bei einer Vereinbarung auswählen kannst. Diese Anleitung setzt voraus, dass du bereits im [Sponsoring-Modul](sponsoring) bist.

## Paketübersicht

Klicke im Sponsoring-Dashboard oben rechts auf **Pakete**. Für jedes Paket sind Name, Beschreibung, Mindestbetrag und eine Farbe für die Anzeige als Badge hinterlegt.

![Paketübersicht](images/sponsoring/09-packages.png)

- Ein **neues Paket** legst du über die Eingabezeile am Ende der Tabelle an.
- Ein bestehendes Paket bearbeitest du über **Bearbeiten**.
- Über das Dropdown-Menü kannst du ein Paket löschen.

## Häufige Stolperfallen

- **Name ist Pflicht.**
- **Mindestbetrag** akzeptiert Komma oder Punkt als Dezimaltrennzeichen (z. B. `2500,00` oder `2500.00`).
- **Ein Paket lässt sich nicht löschen, solange noch Vereinbarungen damit verknüpft sind.** Entferne zuerst das Paket aus den betroffenen Vereinbarungen oder lösche diese.
